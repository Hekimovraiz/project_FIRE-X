# Code of Conduct

FIRE-X is built by students and welcomes contributors of every background, language and level of experience.

## Our standards

- Be respectful and assume good intent.
- Give and accept constructive feedback gracefully.
- Credit others' work, including the NASA scientists whose data make this project possible.
- Be honest about data: never overstate what a result shows.

Harassment, insults, discriminatory language, and publishing others' private information are not acceptable.

## Enforcement

Maintainers may remove comments, commits or contributions that break these rules, and may block repeat offenders. Report problems privately to the maintainers through GitHub.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
